# MySocial - Full Social Media Platform

A complete social media application built with Django REST Framework (backend) and vanilla HTML/CSS/JavaScript (frontend).

## Features

- User registration & login (JWT authentication)
- Create text posts
- Like/unlike posts
- Comment on posts
- Follow/unfollow users
- Personalized feed (your posts + followed users)
- Beautiful, responsive UI
- Fake avatars and sample data
